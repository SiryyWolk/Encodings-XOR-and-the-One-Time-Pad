# Encodings, XOR, and the One-Time Pad

This project is a small educational collection of Python scripts that demonstrate how different text and byte representations work and how XOR is used in symmetric encryption.

The examples focus on several important ideas:

- ASCII encoding
- Base64 encoding
- XOR bitwise operations
- One-time pad encryption
- Converting large integers into byte arrays

All of the code is stored in the Practical-3 folder.

## Project structure

- ASCII.py — converts text to ASCII numbers and back again
- xor.py — demonstrates XOR algebra and properties
- one_time_pad.py — implements a simple one-time pad cipher
- Base64.py — converts hexadecimal data into Base64 text
- Encrypted_Message_ASCII.py — stores an example ASCII-encoded message
- bignum_converter.py — converts a very large integer into raw bytes
- ASCII_Encrypted.txt — stores the ASCII values generated by the encryption step
- ASCII_Decrypted.txt — stores the plaintext recovered during decryption

## 1. ASCII.py

This script shows the simplest form of text representation: ASCII.

ASCII assigns each character a numeric value from 0 to 127. For example:

- A = 65
- a = 97
- space = 32
- H = 72
- e = 101

The script supports two modes:

- -e: encrypt a message into ASCII values
- -d: decrypt those values back into text

Example:

```bash
cd Practical-3
python3 ASCII.py -e
```

When you type a message, it is encoded into a list of integer values, such as:

```python
[72, 101, 108, 108, 111]
```

This is the ASCII representation of "Hello".

The encrypted list is saved in ASCII_Encrypted.txt, and the decoded plaintext is saved in ASCII_Decrypted.txt.

Important point: ASCII is only a text encoding, not encryption. Anyone who sees the numeric values can decode them easily.

## 2. xor.py

This file demonstrates XOR (exclusive OR), a bitwise operation used in many cryptographic systems.

XOR works on binary digits:

- 0 XOR 0 = 0
- 0 XOR 1 = 1
- 1 XOR 0 = 1
- 1 XOR 1 = 0

The program uses a helper function:

```python
def xor_bytes(bytes_seq_1, bytes_seq_2):
    return bytes([a ^ b for a, b in zip(bytes_seq_1, bytes_seq_2)])
```

It then demonstrates important XOR properties:

- Commutative: A XOR B = B XOR A
- Associative: (A XOR B) XOR C = A XOR (B XOR C)
- Identity: A XOR 0 = A
- Self-inverse: A XOR A = 0

This is the key idea behind XOR-based ciphers. Because XOR is reversible, the same operation can be used to encrypt and decrypt:

```python
ciphertext = plaintext XOR key
plaintext = ciphertext XOR key
```

## 3. one_time_pad.py

This script implements a one-time pad, which is a classic example of theoretically secure encryption.

The program does the following:

1. Reads a plaintext string
2. Converts it to bytes
3. Generates a random key of the same length
4. XORs each byte of the plaintext with the corresponding byte of the key
5. Prints the key and ciphertext in hexadecimal form

In decryption mode, it reads the key and ciphertext, XORs them again, and reconstructs the original plaintext.

Important requirements for a real one-time pad:

- the key must be truly random
- the key must be at least as long as the message
- the key must never be reused
- both sender and receiver must keep the key secret

The script checks that the plaintext and key lengths match before performing XOR. This avoids invalid operations and makes the example easier to follow.

This is why the one-time pad is considered unbreakable in theory: if the key is secret, random, and never reused, the ciphertext reveals no useful information about the plaintext.

## 4. Base64.py

This file demonstrates Base64 encoding.

Base64 is not encryption. It is a way of representing binary data using printable text characters. It is often used for email attachments, URLs, and data transfer formats.

The script starts with a hexadecimal string:

```python
42617365363420697320776964656C79207573656420666F72207365
6E64696E6720652D6D61696C206174746163686D656E74732E
```

It converts that hex text into bytes and then encodes it using Base64.

The output is a Base64 string such as:

```text
QmFzZTY0IGlzIHdpZGVseSB1c2VkIGZvciBzZW5kaW5nIGUtbWFpbCBhdHRhY2htZW50cw==
```

This decodes to the text: "Base64 is widely used for sending e-mail attachments".

## 5. Encrypted_Message_ASCII.py

This file is a simple example of ASCII-encoded text stored as a Python list:

```python
encrypted_message_ascii = [72, 101, 108, 108, 111, 32, 65, 83, 67, 73, 73]
```

This is the numeric form of the string:

```text
Hello ASCII
```

It is useful as a compact demonstration of how characters are represented as byte values.

## 6. bignum_converter.py

This script shows how a very large integer can be converted into raw binary data.

It starts with a huge integer value stored in the variable bignum and then calculates:

```python
size_in_bytes = (bignum.bit_length() + 7) // 8
```

This determines how many bytes are needed to represent the number without wasting space.

Then it does:

```python
x = bignum.to_bytes(size_in_bytes)
```

This converts the integer into a byte sequence. This is useful in cryptography and computer security, where numbers are often represented as bytes when transmitted or stored.

## Learning goals

This project is designed to illustrate that:

- text can be represented as numbers
- different encodings preserve the same data in different forms
- XOR is a reversible bitwise operation
- XOR is the core building block of one-time pad encryption
- Base64 and ASCII are not the same as secure encryption

## Summary

These scripts together teach the difference between:

- encoding: changing representation without secrecy
- encryption: hiding information using a key
- XOR: a reversible operation used in many cryptographic systems
- one-time pad: a theoretically secure cipher when keys are random and never reused

This repository is best viewed as a practical introduction to encoding, binary data, and basic cryptography.
